sphinxcontrib-matlabdomain¶

New to Sphinx? Start with the Sphinx primer for MATLAB users and Glossary. Terms such as directive, role, domain and builder link to definitions.

sphinxcontrib-matlabdomain is a Sphinx extension for MATLAB code. It adds a mat domain to Sphinx, with directives and roles for MATLAB functions, classes, scripts, apps and folders, and auto directives that read the help text from the .m and .mlapp files themselves, much like sphinx.ext.autodoc does for Python. Simulink models and libraries are documented too (Simulink files).

It names objects the way MATLAB does: +pkg folders are namespaces, @Cls folders hold a class and its methods, and help text is found where MATLAB’s help finds it. Three tools come with it:

  • scmd quickstart sets up the documentation of a MATLAB project: conf.py, the make files and the API pages, with defaults read from the project;

  • scmd apidoc writes pages for every file of a project, so a large project needs no hand-written directives;

  • the matlab-api-check builder checks that functions, classes and methods have help text, and that it describes their inputs, outputs and name-value arguments, for example in CI.

A conf.py and a page that document one function:

extensions = ["sphinxcontrib.matlab"]
matlab_src_code_project_root = "../src"  # relative to conf.py folder

.. mat:autofunction:: times_two

Quickstart shows the result.

It needs Python 3.11 or newer and Sphinx 8.0 or newer, and is tested on Linux, Windows and macOS. Start with Installation.
